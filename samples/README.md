# Sample document

`kalici-ogrenme.pdf` — *Kalıcı Öğrenme: Kanıta Dayalı Çalışma Tekniklerine Kısa Bir Rehber*, a real 6-page study guide in Turkish, written for PiCODE and released under **CC0**. It covers the forgetting curve, retrieval practice, spacing, interleaving, elaboration, dual coding and metacognition.

It is generated by a dependency-free script, so it can be inspected and rebuilt:

```bash
py samples/make_sample_pdf.py        # Windows
python3 samples/make_sample_pdf.py   # macOS / Linux
```

The PDF uses the standard Helvetica fonts without embedding them. Turkish letters missing from the standard WinAnsi encoding (ğ Ğ ş Ş ı İ) are mapped through a `/Differences` table, so PDF.js extracts correct Unicode text and draws the glyphs with system fonts.

Demo mode (`js/demo-data.js`) quotes this document verbatim and is checked against its extracted text (a browser test verifies every demo quote against the real PDF). If you change the wording, update the demo quotes too.

To try PiCODE with your own documents, just open them in the app (or drop them on the window). Your PDFs are not copied into this folder, and `*.pdf` files other than the sample are git-ignored.
