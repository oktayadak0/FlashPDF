Before you start reading with FlashPDF

FlashPDF can use a few reading signals to personalise your notes. With your permission it records, only inside the PDF viewer:

  • Text you select with the mouse (click and drag), with its page and paragraph — treated as most important.
  • Scrolling speed and direction, to ignore fast scrolling and to recognise re-reading — scrolling back up over lines you just read.
  • Which pages you read, approximate time on each, and pages you return to. Anything under one second is ignored.

Mouse movement, pointer position and hovering are not tracked.

It never records keystrokes, clipboard contents, your screen, other tabs or other apps. Data is stored in this browser and sent only to your local model endpoint when you click Create study note.

These signals are observations, not conclusions. Engine: PiCODE local-first AI.

Privacy & your data

Model settings

PiCODE's backend forwards analysis requests to this runtime. Gemma 4 is the intended model; whatever model you configure is shown by its real name on every result.

This endpoint is not on this computer. PDF excerpts and reading signals would leave your device; PiCODE will ask for confirmation before every analysis.

Help & setup

Demo flow

  1. Open the sample (or your own PDF) and allow reading signals.
  2. Read a few pages, select a passage, go back to an earlier page.
  3. Check the Session tab to see exactly what was recorded.
  4. Click Create study note. Gemma 4 writes one continuous note; pages you spent the most time on get the most detailed sections. Click a page badge or quote to jump to its source.
  5. Save the note and export it as Markdown or JSON.

Running Gemma 4 locally

For local analysis, install Ollama and download the default model. In a terminal:

ollama pull gemma4:e2b
ollama serve

Then open Model settings, keep http://127.0.0.1:11434 and gemma4:e2b, and click Test connection. Run ollama list to see which tags you have. Memory use and analysis time depend on the selected model and your hardware.

Any OpenAI-compatible local server works too (choose that runtime in settings). Such servers do not report a model family, so PiCODE can only check the model name.
